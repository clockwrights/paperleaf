# Security policy

Paperleaf opens untrusted files, so security problems matter. Examples: a PDF that runs code,
opens a link or program without asking, makes a network connection, or a redaction that leaves
the removed content in the saved file.

## Reporting a vulnerability
Please **do not open a public issue**. Use GitHub's private reporting instead: on the repository
page, open **Security › Report a vulnerability**. Include the steps to reproduce and, if possible,
a sample file.

You'll get an answer as soon as possible. Fixes go into the next release, and reporters are
credited unless they prefer not to be.

## Supported versions
Only the latest release receives security fixes.
